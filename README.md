# Med-AI Website Testing

## 1. Introduction

This repository contains two reports for the Software Testing assignment.

The first report explains the role and responsibilities of a Software Tester.

The second report describes how the Med-AI website was tested, including the testing environment, testing process, Test Cases, actual results, identified problems, and final conclusion.

Website under test: [https://medaivn.com/](https://medaivn.com/)

## 2. Repository Contents

1. [Report 1: Introduction to the Software Tester Role](documents/report-1-software-tester.md)
2. [Report 2: Med-AI Website Test Execution](documents/report-2-medaivn-testing.md)
3. `screenshots`: Evidence collected during actual test execution

## 3. Testing Scope

The following public functions are included:

1. Homepage
2. Navigation
3. Medicinal herb search
4. Medical chatbot
5. Symptom analysis
6. Drug interaction checking
7. Medicinal plant image recognition
8. Mobile interface
9. Information and privacy pages

## 4. Testing Method

The Med-AI website is evaluated using Black Box Testing and Manual Testing.

The tester interacts with the website from the user perspective, provides valid and invalid input, compares actual results with expected results, and records supporting screenshots.
